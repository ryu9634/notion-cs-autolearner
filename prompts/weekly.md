# CS Weekly (Java/Backend) 주간 요약 생성

주말 수동 실행 또는 누적 10주제 도달 시 쓰는 프롬프트다.
`prompts/daily.md` 의 Step 1~2(컨텍스트 로드, DB 스캔)를 먼저 수행한 뒤 아래를 실행한다.

## 실행

1. 마지막 `📊 주간 요약` 페이지의 `Date` 를 찾는다. 없으면 DB 전체가 대상.
2. 그 이후 생성된 학습 페이지를 전부 모은다. 1개도 없으면 "요약할 게 없음"을 보고하고 종료.
3. 주간 요약 페이지 1개를 `notion-create-pages` 로 만든다.

**속성**: `Title` = `📊 주간 요약 — <시작일> ~ <오늘>`, `Category` = `📊 주간 요약`,
`Level` = `요약`, `Date` = 오늘 KST, `Day` = 한글 요일, `Status` = `미복습`

**본문**:

1. **이번 주 다룬 주제** — 카테고리별로 묶은 목록. 각 항목은 Notion 페이지 링크 + 한 줄 요약.
2. **관통하는 큰 그림** — 이번 주 주제들이 어떻게 연결되는지 1~2문단.
   억지로 엮지 말고, 실제로 연결이 없으면 "이번 주는 분산된 주제였다"고 솔직히 쓴다.
3. **스스로 점검** — 답을 안 보고 설명할 수 있어야 하는 질문 5개. 답은 접은 블록(toggle)에 넣는다.
4. **약한 고리** — 다룬 주제 중 추가 학습이 필요해 보이는 것 1~2개와 이유.
5. **다음 구간 예고** — `curriculum.json` 기준 다음에 나올 주제 3~4개.

마지막에 생성한 페이지 URL과 누적 진도(`완료 N / 160`)를 출력한다.
